# dtour @ IEEE VIS 2026

Slides for the IEEE VIS 2026 short paper talk on
[dtour](https://github.com/flekschas/dtour) ([dtour.dev](https://dtour.dev)).

```sh
git clone --recurse-submodules git@github.com:flekschas/dtour-ieeevis.git
```

## Contents

- `ieee-vis-2026.py` — marimo slide deck
- `paper/` — LaTeX source and figures of the paper
- `dtour/` — dtour source code (git submodule)

## Run

```sh
uvx marimo@latest edit ieee-vis-2026.py --sandbox --no-token
```
